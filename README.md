# 编程猫教学数据工作台

本项目把 CRM 课程、直播上座、完课和教学服务数据汇总为本地工作台，并按授权同步至钉钉工作簿。

## 一键更新与无 Git 更新

工作台首页提供“一键更新工作台”按钮：

- 已安装 Git 且当前目录是仓库时，优先执行安全的快进更新。
- 未安装 Git、不是仓库或无法快进时，自动下载 GitHub `main` 分支 ZIP 并解压覆盖程序文件。
- 更新完成后自动隐藏重启当前工作台。
- 本机的 `dashboard-config.json`、`share-config.json`、`instances/`、CRM 登录资料、运行数据、看板快照、日志和密钥均不会被覆盖。

新电脑首次部署可直接下载并解压：[main 分支 ZIP](https://github.com/xuechao111/wmzf/archive/refs/heads/main.zip)。完成配置后，以后直接点击首页按钮更新即可。

## 给其他组长使用

1. 将项目复制到组长电脑。
2. 安装 `chrome-extension` 文件夹中的 Chrome 连接器，并登录自己的 CRM。
3. 启动工作台后点击首页右下角的“配置面板”。
4. 填写工作台名称、钉钉工作簿、管理员提供的钉钉连接信息、班级 ID 与主课期 ID。
5. 保存后执行一次手动更新，确认数据和更新时间。

班级配置每行格式为 `班级ID,主课期ID`。如果留空，工作台会继续从钉钉工作簿的“班级id”子表读取，兼容原有操作方式。

首次部署必须同时满足：Chrome 中只启用一份本项目的 `1.6.5` 连接器、已登录 CRM、已填写钉钉连接地址和访问密钥、已填写班级配置（或目标工作簿存在有效的“班级id”子表）。测试工作台会主动检查这些可移植配置，缺失时禁止启动更新并显示具体原因，不会借用正式工作台的运行状态。

## 配置隔离

每台电脑的 `dashboard-config.json`、CRM 登录状态和运行数据均相互独立。仓库只提供 `dashboard-config.example.json` 示例，不提交真实访问密钥、CRM 浏览器资料、学员数据、运行日志或生成后的看板快照。

## 测试工作台副本

双击 `启动测试工作台.bat` 会打开 `http://127.0.0.1:8766/`。正式工作台仍使用 `8765`。

两套工作台共用本仓库中的程序代码，因此后续代码修改会同时生效；测试工作台的配置、状态、缓存和生成数据保存在 `instances/test`，与正式工作台完全隔离。测试副本首次启动不配置任何钉钉目标，必须在配置面板中填写专门的测试工作簿后才能同步，避免误写正式数据。

## 稳定性保护

- 更新失败时保留上一版有效看板。
- 直播数据以 CRM 直播上座接口为准。
- 课程按真实 `course_number` 配对，避免插入课造成重复统计。
- 自动更新具有运行锁、超时恢复和重复时段保护。
- 正式工作台与测试工作台分别保存运行锁、自动更新时间和运行日志；双连接器或重复点击会并入当前任务，不会覆盖为失败。
- 共享页默认只读，配置及更新接口仅允许本机访问。
