# 编程猫教学数据工作台（macOS 独立版）

本目录是单独维护的苹果电脑版本，不会读取或修改 Windows 主看板的程序目录。首次使用请右键打开 `首次安装一键配置.command`，以后双击 `启动组长工作台.command`。运行配置固定保存在 `~/Library/Application Support/CodeMaoTeachingWorkbench/data`，程序升级、移动目录和关机重启均不会清空。

完整步骤见 `MAC使用说明.txt`。页面内的一键更新仅使用 GitHub 的 `macos` 分支，不会用 Windows 主分支覆盖苹果版本。

本项目把 CRM 课程、直播上座、完课和教学服务数据汇总为本地工作台，并按授权同步至钉钉工作簿。

## 一键更新与无 Git 更新

工作台首页提供“一键更新工作台”按钮：

- 已安装 Git 且当前目录是仓库时，优先执行安全的快进更新。
- 未安装 Git、不是仓库或无法快进时，会依次尝试 Codeload、GitHub 和 GitHub API 下载 ZIP。
- 无法连接远程服务器时，把最新版 ZIP 重命名为 `工作台离线更新包.zip`，放进工作台目录，再点击“一键更新工作台”即可离线覆盖更新。
- 更新完成后自动隐藏重启当前工作台。
- 本机配置、CRM 登录资料、运行数据、看板快照、日志和密钥保存在 `%LOCALAPPDATA%\CodeMaoTeachingWorkbench\data`，关机、退出、重新解压 ZIP 和一键更新均不会覆盖。

新电脑首次部署可直接下载并解压：[main 分支 ZIP](https://github.com/xuechao111/wmzf/archive/refs/heads/main.zip)。完成配置后，以后直接点击首页按钮更新即可。

## 给其他组长使用

1. 下载并解压 GitHub ZIP。
2. 首次使用双击 `首次安装一键配置.bat`，脚本会检测并补齐 Python、Node.js、Chrome，创建本机配置和桌面快捷方式。
3. 根据自动打开的 Chrome 扩展页提示，开启开发者模式，点击“加载已解压的扩展程序”，选择 ZIP 内的 `chrome-extension` 文件夹。这一步受 Chrome 安全限制，必须由使用者确认一次。
4. 日常使用双击桌面的“编程猫教学数据工作台”，或运行 `启动组长工作台.bat`；不要使用仅供副本验证的 `启动测试工作台.bat`。
5. 登录自己的 CRM，打开工作台配置面板。
6. 填写工作台名称、钉钉工作簿、管理员提供的钉钉连接信息、班级 ID 与主课期 ID。
7. 保存后执行一次手动更新，确认数据和更新时间。

班级配置每行格式为 `班级ID,主课期ID`。如果留空，工作台会继续从钉钉工作簿的“班级id”子表读取，兼容原有操作方式。

分发版首次部署必须同时满足：Chrome 中只启用一份本项目的 `1.6.5` 连接器、已登录 CRM、已填写钉钉文档链接和钉钉连接地址、已填写班级配置（或目标工作簿存在有效的“班级id”子表）。分发版不显示也不要求钉钉访问密钥；连接地址需要自身具备授权能力。

启动器会验证 Python 3.9 及以上、Node.js 18 及以上；电脑只有旧版本时会自动安装隔离的便携运行环境，不修改原有软件。

## 配置隔离

每台电脑的配置、CRM 登录状态和运行数据都保存在该 Windows 用户自己的 `%LOCALAPPDATA%\CodeMaoTeachingWorkbench\data`，相互独立。旧版首次升级时会自动迁移解压目录中的现有配置；仓库只提供配置示例，不提交密钥、CRM 浏览器资料、学员数据、运行日志或生成后的看板快照。

## 测试工作台副本

双击 `启动测试工作台.bat` 会打开 `http://127.0.0.1:8766/`。正式工作台仍使用 `8765`。

两套工作台共用本仓库中的程序代码，因此后续代码修改会同时生效；测试工作台的配置、状态、缓存和生成数据保存在 `instances/test`，与正式工作台完全隔离。测试副本首次启动不配置任何钉钉目标，必须在配置面板中填写专门的测试工作簿后才能同步，避免误写正式数据。

## 稳定性保护

- 更新失败时保留上一版有效看板。
- 直播数据以 CRM 直播上座接口为准。
- 课程按真实 `course_number` 配对，避免插入课造成重复统计。
- 自动更新具有运行锁、超时恢复和重复时段保护。
- 正式工作台与测试工作台分别保存运行锁、自动更新时间和运行日志；双连接器或重复点击会并入当前任务，不会覆盖为失败。
- 共享页默认只读，配置及更新接口仅允许本机访问。
